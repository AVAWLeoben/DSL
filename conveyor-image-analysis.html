For this version, P1 counts distinct RGB pixel colors. Each unique color is one exact (R,G,B) triplet. This makes the effect of JPEG compression on a classified image directly visible: a lossless image contains only the intended class colors plus black background, while JPEG introduces many additional RGB combinations. JPEG is lossy, so exact RGB class values are altered near edges and blocks. Depending on image content and quality, compression may create more or fewer unique channel values; the important observation is that exact classified colors are no longer preserved.

As in the MATLAB example, black is treated as conveyor background and every non-black pixel is treated as material. Objects are placed irregularly with a small separation gap, so connected-component count still approximately corresponds to the generated object count without forcing them onto a regular grid.

12 vertical load zones

The image width is intentionally 312 pixels, matching the MATLAB script. Red lines mark the 12 vertical divisions. Each object's exact rectangular pixel overlap with each zone is accumulated over all 700 frames. The generator uses drifting loading hotspots, so the resulting distribution is intentionally non-uniform.
