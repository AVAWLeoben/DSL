✓
Local file processing. Files are never uploaded to this website. Browser-only mode uses your browser's folder permissions. Local-helper mode runs on 127.0.0.1, sends paths and progress only to that helper, and copies files directly on your computer or accessible network shares. No third-party JavaScript libraries, compression, or Brotli decoding.
Cross-browser setup: Keep parallel-folder-sync.html at repository root and place the helper at tools/fast-folder-sync-helper.cjs. Install an up-to-date, security-patched Node.js, run node tools/fast-folder-sync-helper.cjs from the repository root, then open http://127.0.0.1:8765/ in any modern browser. The local helper is required for Firefox/Safari and recommended for SMB shares. Safety: use a non-administrator account, preview every mirror, and test on disposable folders first. No silent background service is installed.
