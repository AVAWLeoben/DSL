Private, browser-only copying. Files stay on your computer or the storage locations you choose; no file contents are uploaded to this site. No account, installation, backend, or external JavaScript libraries are needed. The browser controls which folders can be accessed.
Browser requirement: Use a recent Chromium-based browser such as Google Chrome or Microsoft Edge with the File System Access API. Open this page over HTTPS (for example, GitHub Pages) or localhost. Firefox and Safari are not supported. Safety: Mirror deletes matching extra destination files after copying; always review the preview and test on disposable folders. The browser may not preserve original timestamps or Windows file permissions. A preview is not a snapshot: files can change after scanning.
