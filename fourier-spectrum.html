Fourier transformation · spectral analysis

What frequencies are hidden inside a signal?

A complicated waveform in the time domain can be built from much simpler sinusoidal components. Run the Fast Fourier Transform (FFT) to convert this fixed signal into a frequency spectrum, where each peak reveals a component frequency and its amplitude.

The mathematics

X[k] = Σ x[n] · e−j2πkn/N

f[k] = k · fs / N
Δf = fs / N = 1 Hz

For a real-valued signal the FFT contains mirrored positive and negative frequencies. This exercise plots only the positive half, from 0 Hz to the Nyquist frequency.

Teaching note

The waveform may look irregular, but it is only the sum of three pure tones. The FFT does not invent new frequencies—it changes the representation so the components become directly visible.
