Export details: Uses Chromium WebCodecs to encode H.264/AVC. Bitrate is a target, not a guaranteed output rate. Sharp UI mode uses all keyframes to improve screenshot detail. Select First image dimensions to avoid scaling. Lossless AVI stores uncompressed 24-bit BGR frames with exact frame rate; file sizes are large (about 6 MB per 1920×1080 frame). MP4 uses Chromium WebCodecs H.264 and is lossy even at high bitrate. No external libraries, network access or real-time recording. AVI uses standard uncompressed DIB frames, readable by many OpenCV installations; verify your particular SenSoRTC playback backend.
